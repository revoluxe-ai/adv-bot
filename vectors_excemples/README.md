# Векторные представления из Redis

## Описание полученных данных

### Векторы товаров (item_vector)
В файлах `item_vector_example.txt` и `item_vector_example2.txt` содержатся примеры векторных представлений товаров из Redis. Каждый вектор представляет собой массив из 16 чисел с плавающей точкой. Ключи имеют формат `item_vector:{nmid}`, где `{nmid}` - это ID товара в Wildberries.

Примеры ключей:
```
item_vector:238144032
item_vector:140294026
item_vector:181657334
item_vector:180842244
item_vector:163167116
...
```

### Векторы ключевых слов (keyword_vector)
В базе также хранятся векторные представления ключевых слов с префиксом `keyword_vector:`. К сожалению, из-за проблем с кодировкой не удалось корректно получить содержимое этих векторов, но ключи имеют следующий формат:

```
keyword_vector:{keyword_text}
```

Где `{keyword_text}` - это текст ключевого слова на русском языке.

## Использование векторов

Эти векторные представления используются для семантического поиска и сопоставления товаров с поисковыми запросами. Векторы получены с помощью нейронной сети и представляют семантическое значение товаров и ключевых слов в многомерном пространстве.

Функциональность для обновления этих векторов реализована в модуле NeoDataScience и скрипте `run_update_keyword_vectors_in_redis.py`.
