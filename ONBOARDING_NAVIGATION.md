# Навигация после входа (онбординг)

Краткое описание структуры экранов после команды `/start` и переходов между ними (актуально после рефакторинга главного меню и списка магазинов).

## Два уровня экранов

1. **Главное меню (MainMenu)**  
   Показывается после `/start` или callback **Start** (`callbacks.Start()`).
   - Кнопки: **Мои магазины**, **Мой баланс**, **Показать инвайт**
   - Для администраторов дополнительно: **Панель администратора**
   - Реализация: `MainMenu`, `get_main_menu_keyboard()` в `shop_choice_message.py`

2. **Страница «Мои магазины» (ShopsListPage)**  
   Показывается по callback **ShowShopsList** (`callbacks.ShowShopsList()`).
   - Кнопка **➕Добавить магазин**
   - Список магазинов (название + ✅/❌: подключен / требуется замена токена)
   - Пагинация по 20 магазинов (⬅️ Назад / Вперёд ➡️)
   - Кнопка **Назад** — возврат в главное меню (Start)
   - Реализация: `ShopsListPage`, `get_shops_list_keyboard()` в `shop_choice_message.py`

## Важные переходы

| Действие пользователя | Callback | Результат |
|------------------------|----------|-----------|
| Нажал «Мои магазины» в главном меню | `ShowShopsList` | Открывается страница «Мои магазины» |
| Нажал «Вернуться к списку магазинов» (из меню магазина) | `ShowShopsList` | Открывается страница «Мои магазины» |
| Нажал «К списку магазинов» (например, с экрана оплаты) | `ShowShopsList` | Открывается страница «Мои магазины» |
| Нажал «Назад» на странице «Мои магазины» | `Start` | Возврат в главное меню |
| «Перейти в главное меню» (из рассылок и т.п.) | `Start` | Возврат в главное меню |

Итого: кнопки возврата **к списку магазинов** ведут на страницу «Мои магазины», а не в главное меню. В главное меню пользователь попадает по `/start`, по кнопке «Назад» на странице «Мои магазины» или по кнопке «Перейти в главное меню» там, где она есть.
