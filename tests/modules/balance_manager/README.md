# Тесты для модуля balance_manager

## Обзор покрытия тестами

Всего тестов: **34**

### Файлы с тестами:

1. **test_balance_service.py** (5 тестов)
   - Базовые тесты для `process_payment_with_bonus`
   - Проверка начисления 200% бонуса
   - Проверка нулевого процента
   - Валидация отрицательных значений
   - Различные проценты

2. **test_balance_service_comprehensive.py** (12 тестов)
   - Дробные проценты
   - Отрицательные суммы
   - Передача description
   - Обработка ошибок от add_balance/add_bonus
   - Очень маленькие и большие суммы
   - Формат описания бонуса

3. **test_balance_service_edge_cases.py** (5 тестов)
   - Граничные случаи с процентами (0, очень маленькие, очень большие)
   - Структура возвращаемых значений
   - Точность расчетов

4. **test_handlers_bonus_date.py** (3 теста)
   - Начисление бонуса до конца 2025 года
   - Отсутствие бонуса после 2025 года
   - Последний день 2025 года

5. **test_handlers_comprehensive.py** (6 тестов)
   - Пользователь не найден
   - Различные суммы платежей
   - Вызов BalanceUpdated
   - Вызов ShopMenu
   - Граничные случаи с датами
   - Проверка description

6. **test_settings_bonus_percent.py** (4 теста)
   - Значение по умолчанию (200%)
   - Значение из переменной окружения
   - Невалидные значения
   - Отрицательные значения

## Запуск тестов

```bash
# Все unit-тесты модуля balance_manager
pytest tests/modules/balance_manager/ -v

# Конкретный файл
pytest tests/modules/balance_manager/test_balance_service.py -v

# Конкретный тест
pytest tests/modules/balance_manager/test_balance_service.py::test_process_payment_with_bonus_200_percent -v

# Интеграционные тесты (требуют Docker Compose)
pytest tests/integration/balance_manager/ -v -m integration
```

## Примечания

- Все тесты используют моки для изоляции от БД
- Тесты для handlers мокируют все внешние зависимости (БД, сообщения, меню)
- Тесты для settings проверяют работу с переменными окружения
- Граничные случаи покрывают все возможные сценарии использования

## Интеграционные тесты

Для проверки работы с реальной БД см. `tests/integration/balance_manager/`:
- 13 интеграционных тестов для `balance_service`
- 3 интеграционных теста для `handlers`
- Все тесты используют реальную PostgreSQL БД через docker-compose
- Транзакции автоматически откатываются после каждого теста
