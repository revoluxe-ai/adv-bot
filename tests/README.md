# Тесты проекта

## Проверка циклических импортов

В проекте настроена автоматическая проверка циклических импортов для всех точек входа, перечисленных в документации (`app/docks/entry_points.md`).

### Запуск тестов циклических импортов

Для запуска тестов циклических импортов можно использовать специальный скрипт:

```bash
# Активируйте виртуальное окружение
source ./.venv/Scripts/activate  # Windows (Git Bash)
source .venv/bin/activate        # Linux/MacOS

# Запустите скрипт проверки
python tests/run_circular_imports_test.py
```

Или напрямую через pytest:

```bash
python -m pytest tests/test_circular_imports.py -v
```

### Добавление новых точек входа

При добавлении новых точек входа в приложение:

1. Добавьте информацию о новой точке в документацию (`app/docks/entry_points.md`)
2. Добавьте путь к файлу точки входа в список `ENTRY_POINTS` в файле `tests/test_circular_imports.py`

### Как работает проверка

Тесты используют библиотеку `pycycle` для анализа импортов и поиска циклических зависимостей. Циклические импорты могут вызывать следующие проблемы:

- Непредсказуемое поведение при импорте
- Замедление загрузки модулей
- Возможные ошибки и исключения
- Затруднение рефакторинга и тестирования

### Исправление циклических импортов

Если тесты обнаружили циклические импорты, вы можете исправить их следующими способами:

1. **Перемещение импортов внутрь функций/методов**: Вместо импорта на уровне модуля, импортируйте внутри функций или методов.
   ```python
   # Вместо:
   from module_b import function_b
   
   # Используйте:
   def function_a():
       from module_b import function_b
       # ...
   ```

2. **Использование импорта в точке использования**: Импортируйте только там, где необходимо.

3. **Реорганизация кода**: Выделите общую функциональность в отдельный модуль, который импортируется обоими модулями.

4. **Использование интерфейсов**: Создайте модуль с абстрактными классами/интерфейсами для разрыва циклических зависимостей.

## Интеграция с CI

Тесты циклических импортов автоматически запускаются в CI для обеспечения качества кода.
