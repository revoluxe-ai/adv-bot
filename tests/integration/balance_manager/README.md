# Интеграционные тесты для модуля balance_manager

## Обзор

Интеграционные тесты проверяют работу модуля balance_manager с реальной базой данных PostgreSQL. Все тесты используют фикстуру `async_session` из `conftest.py`, которая создает транзакцию с автоматическим откатом после каждого теста.

## Файлы с тестами

### test_balance_service_integration.py (13 тестов)

Проверяет работу функций `balance_service` с реальной БД:

- ✅ `add_balance` - создание записи о пополнении баланса
- ✅ `add_bonus` - создание записи о начислении бонусов
- ✅ `process_payment_with_bonus` - комплексная обработка платежа с бонусом 200%
- ✅ `process_payment_with_bonus` - обработка платежа без бонуса (0%)
- ✅ Множественные платежи накапливаются
- ✅ `get_cabinet_balance` - получение баланса и бонусов
- ✅ Обработка ошибок (UserNotFoundError, CabinetNotFoundError)
- ✅ Валидация (отрицательные суммы, нулевые суммы, отрицательные проценты)
- ✅ Учет начального баланса кабинета
- ✅ Формат описания бонуса
- ✅ Работа с дробными суммами

### test_handlers_integration.py (3 теста)

Проверяет работу `successful_payment_handler` с реальной БД:

- ✅ Обработка платежа с бонусом до конца 2025 года
- ✅ Обработка платежа без бонуса после 2025 года
- ✅ Обработка случая когда пользователь не найден

## Запуск тестов

```bash
# Все интеграционные тесты balance_manager
pytest tests/integration/balance_manager/ -v -m integration

# Конкретный файл
pytest tests/integration/balance_manager/test_balance_service_integration.py -v

# Конкретный тест
pytest tests/integration/balance_manager/test_balance_service_integration.py::test_process_payment_with_bonus_integration_200_percent -v
```

## Требования

- Docker Compose должен быть установлен и доступен
- Тестовая БД будет автоматически поднята через docker-compose
- Все тесты используют транзакции с автоматическим откатом

## Примечания

- Все тесты изолированы друг от друга благодаря транзакциям
- Каждый тест создает свои тестовые данные (User, WBCabinet)
- После каждого теста все изменения откатываются автоматически
- Тесты проверяют реальное взаимодействие с БД, а не только моки
