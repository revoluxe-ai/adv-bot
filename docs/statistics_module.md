# Модуль статистики

## Общее описание

Модуль статистики отвечает за сбор, обработку и отображение данных о рекламных кампаниях. Он интегрируется с API Wildberries, ClickHouse базой данных и Redis для кэширования, предоставляя детальную аналитику по рекламным кампаниям.

## Структура данных

### Основные классы

1. **FullAdvStat** - полная статистика по рекламной кампании
   - Содержит агрегированные данные по всей кампании
   - Включает список DayStat для детализации по дням
   - Хранит информацию о позициях товаров (boosterStats)

2. **DayStat** - статистика за конкретный день
   - Содержит метрики за один день
   - Включает разбивку по платформам (apps)

3. **CommonCardStat** - общая статистика по карточке товара
   - Открытия карточки (open_card)
   - Добавления в корзину (add_to_cart)
   - Заказы (orders)
   - Сумма заказов (orders_sum)
   - Выкупы (buy_outs)

4. **SimpleStat** - упрощенная статистика
   - Базовые метрики: просмотры, клики, CTR, CPC, расходы

### Отслеживаемые метрики

- Просмотры (views)
- Клики (clicks)
- CTR (показатель кликабельности)
- CPC (средняя стоимость клика)
- Расходы (sum/spend)
- Добавления в корзину (atbs)
- Заказы (orders)
- Конверсия (cr)
- Количество заказанных товаров (shks)
- Сумма заказов (sum_price)

## Источники данных

1. **Wildberries API**
   - Основной источник данных
   - Эндпоинт: seller-analytics-api.wildberries.ru
   - Предоставляет актуальную статистику по кампаниям

2. **ClickHouse**
   - Хранение исторических данных
   - Быстрый доступ к агрегированным показателям
   - Поддержка сложных аналитических запросов

3. **Redis**
   - Кэширование актуальных данных
   - Быстрый доступ к часто запрашиваемой статистике
   - Снижение нагрузки на API и базу данных

## Процесс работы

### Получение данных

1. **Обновление статистики**
   - Регулярное обновление через API Wildberries
   - Сохранение в ClickHouse
   - Кэширование в Redis

2. **Получение статистики**
   - Поддержка различных периодов (последние 3 дня, конкретный период)
   - Разделение по типам рекламы (авто-реклама, аукцион)
   - Агрегация данных по различным параметрам

### Обработка данных

1. **Расчет метрик**
   - Среднее количество заказов
   - Стоимость заказа
   - Эффективность кампании
   - ROI и другие показатели

2. **Фильтрация и сортировка**
   - По датам
   - По типам рекламы
   - По эффективности

## Отображение данных

### В интерфейсе бота

1. **AdvSettingMenu**
   - Основная информация о кампании
   - Статистика за последние дни
   - Себестоимость заказа
   - Расходы и эффективность

2. **AdvKeywordsSetting**
   - Статистика по ключевым словам
   - Эффективность различных типов рекламы
   - Планы и фактические показатели

### Экспорт данных

1. **CSV формат**
   - Экспорт полной статистики
   - Поддержка различных периодов
   - Разбивка по магазинам и кампаниям

## Интеграция с другими модулями

1. **Управление рекламными кампаниями**
   - Использование статистики для оптимизации
   - Автоматическая корректировка ставок
   - Управление бюджетом

2. **Система ключевых слов**
   - Анализ эффективности ключевых слов
   - Управление минус-словами
   - Оптимизация семантического ядра

3. **Прогнозирование**
   - Использование исторических данных
   - Прогноз CTR
   - Оценка эффективности кампаний

## Технические детали

### Основные функции

```python
async def get_stats_by_last_days(adv_ids: list[int], start_date: datetime, end_date: datetime) -> SmallFullAdvStat
```
- Получение статистики за указанный период
- Агрегация данных по нескольким кампаниям

```python
async def get_full_adv_stat_for_adv_id_from_redis(adv_id: int) -> Optional[FullAdvStat]
```
- Получение кэшированной статистики
- Быстрый доступ к актуальным данным

```python
async def get_stats_for_last_period(nmid: int, days: int) -> Optional[CommonCardStat]
```
- Получение статистики по карточке товара
- Расчет показателей за указанный период

### Обработка ошибок

- Повторные попытки при сбоях API
- Логирование ошибок
- Возврат дефолтных значений при отсутствии данных
