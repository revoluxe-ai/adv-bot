# 🚀 Экспонента CTR - Быстрая справка

> 💡 Для подробного описания см. [EXPONENTA_GUIDE.md](./EXPONENTA_GUIDE.md)

---

## ⚡ Основная формула

```
rating = predict_ctr ^ exponent × views
```

**Где:**
- `predict_ctr` — прогнозируемый CTR (0.0-1.0, например 0.05 = 5%)
- `exponent` — экспонента (настраиваемый параметр, обычно 0.5-2.0)
- `views` — количество показов

---

## 🎯 Что делает экспонента?

| Значение | Приоритет | Применение |
|----------|-----------|-----------|
| **> 1.0** | Качество (высокий CTR) | Премиум-товары, нишевые продукты |
| **= 1.0** | Сбалансированный | Универсальные товары |
| **< 1.0** | Объем (показы) | Массовые товары, распродажи |

---

---

## 🎚️ Статусы ключевых слов (hard_status)

| Статус | Название | Поведение |
|--------|----------|-----------|
| **-1** | Тестирование | Повышение ставки для теста |
| **0** | Черный список | Автоматически выключен ❌ |
| **1** | Авто режим | Бот управляет вкл/выкл |
| **2** | Белый список | Всегда включен ✅ |
| **3** | Выключено | Отключено вручную ❌ |

---

## 🤖 Как работает биддер?

1. **Выбирает** best_keyword из белого списка по `rating_by_predict_ctr` ⭐
2. **Парсит** текущую позицию товара по этому ключу
3. **Корректирует** ставку CPM:
   - Позиция хорошая → снижает ставку
   - Позиция плохая → повышает ставку
4. **Обновляет** CPM на Wildberries

**Влияние экспоненты:** Определяет, каким ключевым словом управляет биддер!

- **Высокая экспонента** → Биддер управляет качественным трафиком (высокий CTR)
- **Низкая экспонента** → Биддер управляет массовым трафиком (большие показы)

## 🔧 Как изменить?

### Через Telegram-бот:
1. Настройки кампании → **"Изменить экспоненту прог. ctr"**
2. Ввести значение (например, `1.2`)

### Через SQL:
```sql
UPDATE adv_setting 
SET exponent_predict_ctr = 1.2 
WHERE adv_id = 12345678;
```

## 💡 Быстрые примеры

### Пример 1: Две фразы
| Фраза | CTR | Показы | exp=1.0 | exp=1.5 | exp=0.7 |
|-------|-----|--------|---------|---------|---------|
| "Футболка" | 2% | 15000 | 300 | 169 | **643** ⭐ |
| "Футболка премиум" | 7% | 500 | 35 | **46** ⭐ | 82 |

- **exp=1.5**: Система выберет премиум-фразу (качество)
- **exp=0.7**: Система выберет общую фразу (объем)

### Пример 2: Влияние на автодобавление
При добавлении фразы в белый список система выбирает TOP-1 по рейтингу:

```python
keywords.sort(key=lambda kw: kw.rating_by_predict_ctr, reverse=True)
keyword_for_adding = keywords[0]  # С максимальным рейтингом
```

**Высокая экспонента (1.5)** → Добавит фразу с высоким CTR  
**Низкая экспонента (0.7)** → Добавит высокочастотную фразу

---

## ⚠️ Частые ошибки

❌ **Слишком высокая (> 2.0)** — резкое падение охвата  
❌ **Слишком низкая (< 0.3)** — падение конверсии  
❌ **Забыть изменить при смене стратегии** — неоптимальные результаты  

---

## 🎓 Рекомендации по типам товаров

| Тип товара | Рекомендуемая экспонента | Почему |
|-----------|-------------------------|--------|
| **Премиум** (ювелирка, гаджеты) | 1.3 - 1.8 | Важно качество трафика |
| **Универсальные** (одежда, обувь) | 0.9 - 1.2 | Баланс охвата и качества |
| **Массовые** (канцтовары, хозтовары) | 0.6 - 0.9 | Важен максимальный охват |
| **Сезонные распродажи** | 0.5 - 0.7 | Максимум продаж за короткий срок |
| **Новые товары** | 0.7 - 1.0 | Быстро набрать узнаваемость |

## 🔬 Код (для разработчиков)

**Модель:**
```python
# app/modules/common_slaves/wildberries/models/models.py
exponent_predict_ctr = mapped_column(
    Float,
    nullable=False,
    default=settings.DEFAULT_CTR_EXPONENTA,
)
```

**Расчет рейтинга:**
```python
# app/modules/common_slaves/wildberries/data_classes/keywordstat_from_db.py
@property
def rating_by_predict_ctr(self) -> float:
    if self.predict_ctr is None or self.predict_ctr_exponent is None:
        return 0.0
    rating = self.predict_ctr**self.predict_ctr_exponent * self.views
    return rating
```

**Использование:**
```python
# Сортировка по рейтингу
keywords.sort(key=lambda kw: kw.rating_by_predict_ctr, reverse=True)
best_keyword = keywords[0]
```
