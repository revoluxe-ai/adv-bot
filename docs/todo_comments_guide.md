# Руководство по TODO комментариям в проекте

## Принципы использования

### Типы комментариев
- `# TODO:` - Задачи для будущей реализации
- `# FIXME:` - Код, который нужно исправить
- `# HACK:` - Временные решения, которые нужно переделать
- `# NOTE:` - Важные заметки для разработчиков
- `# XXX:` - Критические проблемы, требующие немедленного внимания

### Формат комментария
```python
# TODO: КАТЕГОРИЯ - Краткое описание проблемы
# Подробное описание проблемы и контекст
# Приоритет: ВЫСОКИЙ/СРЕДНИЙ/НИЗКИЙ, Дата: ДД.ММ.ГГГГ
```

### Примеры

#### Архитектурная проблема
```python
# TODO: АРХИТЕКТУРНАЯ ПРОБЛЕМА - Дублирование базовых классов API
# Существует два похожих базовых класса: BaseAPI и ABC_WB_API
# Нужно провести рефакторинг для объединения или четкого разделения ответственности
# Приоритет: СРЕДНИЙ, Дата: 04.09.2025
class SomeClass:
    pass
```

#### Производительность
```python
# FIXME: ПРОИЗВОДИТЕЛЬНОСТЬ - Медленный запрос к базе данных
# Запрос выполняется без индексов, нужно оптимизировать
# Приоритет: ВЫСОКИЙ, Дата: 04.09.2025
def slow_query():
    pass
```

#### Временное решение
```python
# HACK: Временное решение для обхода бага в библиотеке
# После обновления библиотеки до версии X.X.X можно убрать
# Приоритет: НИЗКИЙ, Дата: 04.09.2025
def workaround():
    pass
```

## Поиск TODO в IDE

### VS Code / Cursor
- Используйте поиск по регулярному выражению: `(TODO|FIXME|HACK|NOTE|XXX):`
- Установите расширение "Todo Tree" для удобного просмотра

### Командная строка
```bash
# Поиск всех TODO комментариев
grep -r "TODO\|FIXME\|HACK\|NOTE\|XXX" --include="*.py" .

# Поиск с контекстом
grep -r -A 2 -B 1 "TODO:" --include="*.py" .
```

## Принципы ведения

1. **Всегда указывайте дату** - чтобы понимать возраст проблемы
2. **Указывайте приоритет** - для планирования работ
3. **Добавляйте контекст** - почему это нужно сделать
4. **Регулярно просматривайте** - не давайте TODO накапливаться
5. **Удаляйте выполненные** - поддерживайте актуальность

## Интеграция с процессом разработки

- При создании PR проверяйте, не добавились ли новые TODO
- В спринт планировании просматривайте высокоприоритетные TODO
- При рефакторинге проверяйте связанные TODO комментарии
