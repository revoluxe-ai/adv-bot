# ai-package-v1-contract-tests Specification

## ADDED Requirements

### Requirement: Contract tests for multi-window analysis

Контрактные проверки MUST покрывать границы окон, исключение неполного текущего дня, агрегаты 1, 3, 7, 30, 90, 180 и 365 дней, календарный год, отсутствие размножения сырых строк, различие пропуска нуля и пустого значения, распространение частичного покрытия и разрыва, идентичность ног Auto и Search, изоляцию прямой и связанной областей, запрет отката связанной метрики к прямой, нулевой знаменатель, недостаточную выборку, несопоставимое сравнение, версии пакета и контракта, стабильный порядок строк и одинаковый доменный результат на шве транспорта. Проверки MUST NOT требовать записи в WB.

#### Scenario: Tampered analysis contract fails validation

- **GIVEN** пакет с аналитическим контрактом
- **WHEN** байты контракта изменены после сборки
- **THEN** проверка пакета MUST завершиться неуспехом

#### Scenario: Uncomputable economics are not numeric

- **GIVEN** нет фактов атрибуции и нет выручки магазина
- **WHEN** проверка читает окно ноги и окно магазина
- **THEN** прямые и связанные экономические метрики и DRR магазина MUST быть невычислимы
- **AND** MUST NOT быть числом ноль
