# Owner Contract

## Что хотим получить

Когда в полках больше нечего тестировать по ставкам и среди уже
протестированных нет ставки под план при текущем допустимом CPO — Авто-РК
ставится на паузу. Допустимый CPO здесь — resolve CPO из настроек плана
продаж: если прогноз заказов уже закрывает план — берётся целевая себестоимость
заказа; если план ещё не закрыт — максимальная себестоимость заказа. Не
«всегда только Max». Управление ставкой в полках при этом не выключается.
Через заданное число суток Авто снова включается для перетеста. Пользователю
понятно, почему пауза (в т.ч. какой CPO учли — цель или макс и значение) и
когда следующий перетест.

## Зачем

Не крутить Авто-ногу вхолостую, когда тест ставок в полках уже исчерпан и
рабочей ставки под план нет. Дать честный «подключил и забыл» с понятной
паузой и шансом перетеста, без ручного отключения модуля полок.

## Что должно остаться неизменным

- Включённое «Управление ставкой в полках» не выключается из‑за этой паузы.
- При включённых полках старый путь «управление ставкой для Авто» по-прежнему
  не пишет ставку.
- Пауза Search из‑за пустых ключей — отдельная история; этот change её не
  меняет.
- Пока «Управление ставкой в полках» включено, обычная пауза Авто по
  себестоимости из контроля активности не действует: при включённом модуле
  полок этот путь не ставит Авто на паузу. Пауза «полки исчерпаны» — отдельная
  причина и не маскируется под паузу по себестоимости.
- Бюджет, расписание, баланс и аварийные ограничения по-прежнему важнее
  автозапуска на перетест.

## Чего сейчас не делаем

- Честную оплату ног Auto/Search при паузе, тариф 1000₽, канал-анонс.
- Паузу Search или обеих ног из‑за исчерпания полок.
- Выключение «Управления ставкой в полках» вместо паузы Авто на WB.
- Перепись математики выбора ставок в полках сверх хука паузы/перетеста.
- Эту паузу при выключенном модуле полок или не в режиме плана по дистанции.

## Как поймём, что получилось

- При включённом «Управление ставкой в полках» (режим плана по дистанции),
  когда тестировать больше нечего и нет ставки под текущий допустимый CPO —
  Авто на WB на паузе, модуль полок остаётся включённым.
- В учёте причин видно отдельную причину паузы и по какому CPO решили
  остановиться.
- В Telegram понятно: почему пауза, какой CPO учли, когда следующий перетест;
  есть кнопка «Сбросить паузу».
- По наступлении интервала (по умолчанию 7 суток) или по кнопке / если на
  тике снова появились подходящие ставки — Авто стартует, начинается новая
  эпоха теста (старая история не «закрывает» покрытие мгновенно).
- Пока ждём перетест, на каждом тике пересчитывается допустимый CPO: нет
  подходящих точек — пауза продолжается.

## Решения Owner

- Допустимый CPO для решения о паузе — текущий resolve CPO (зависит от
  продаж), не «всегда только Max»; в причине/уведомлении указывается, какой
  CPO использовали.
- Пока Авто на этой паузе — на каждом тике перепроверка; появились проходные
  точки — старт Авто без ожидания полного интервала.
- Функционал только если модуль «Управление ставкой в полках» включён; иначе
  не трогаем.
- Календарный перетест ждёт полный интервал суток; ранний выход — кнопка
  «Сбросить паузу» (и автостарт при появлении проходных точек на тике).
- При включённом модуле полок обычная пауза по себестоимости (контроль
  активности) не работает; «полки исчерпаны» — отдельная причина, не подмена
  cost-паузы.
