# Owner Contract

## Что хотим получить

ChatGPT подключается к WB Sky по стандартному OAuth и читает данные магазина через MCP. Человек подтверждает подключение в уже существующем Telegram-боте WB Sky. После этого ChatGPT видит профиль, список магазинов, возможности и AI-пакет только тех магазинов, к которым у этого пользователя есть доступ сейчас.

## Зачем

Нужен удалённый машинный доступ к тем же данным, которые WB Sky уже отдаёт во Full AI Package, без второго смысла данных и без отдельного сайта логина.

## Что должно остаться неизменным

Обычный вход в бота через /start, кабинеты и магазины, сбор данных и управление рекламой. Telegram-сессия и токен бота не становятся ключом к MCP. Запись в Wildberries, ставки, пауза, депозит и ChangeSet из этого подключения не появляются.

## Чего сейчас не делаем

Не делаем сайт логина. Не делаем инструменты записи, проверки или применения ChangeSet. Не поднимаем боевой MCP. Не меняем бота и базу в этом планировании.

## Как поймём, что получилось

ChatGPT проходит OAuth, пользователь подтверждает связь в боте и возвращается в ChatGPT. Чтение магазина работает только пока связь кабинета жива. Отключение в боте сразу закрывает доступ. Чужой shop_id не отдаёт данные. Пакет для модели — те же карточки, пробелы и полнота, что у Full AI Package, а не новый отчёт.

## Решения Owner

MCP первой версии только на чтение. Инструменты: профиль, список магазинов, возможности, AI-пакет. Человеческое согласие — существующий Telegram-бот. Протокол к ChatGPT — OAuth 2.1 Authorization Code + PKCE, конечные точки делает backend WB Sky. Отдельного сайта логина нет. Единственная область доступа — чтение. Список магазинов не зашивается в токен навсегда: сервер каждый раз смотрит текущие кабинеты. Идентификатор Telegram не является bearer-ключом MCP.
