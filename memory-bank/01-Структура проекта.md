# Структура проекта Adv Bot

## Корневой каталог

В корневом каталоге проекта находятся:
- Скрипты запуска различных компонентов (например, `updater.py`, `client_bot_run.py`)
- Файлы конфигурации Docker (`docker-compose.yml`, `Dockerfile.*`)
- Файлы зависимостей (`requirements.txt`, `linux_requirements.txt`)
- Конфигурационные файлы для различных инструментов (`mypy.ini`, `pytest.ini`)

## Основные директории

### `/app`
Основной код приложения:

- `/app/client_bot` - телеграм-бот для пользователей
  - `/user_interface` - компоненты пользовательского интерфейса
  - `/api` - API-эндпоинты для бота
  - `/middlewars` - промежуточные обработчики сообщений
  
- `/app/core` - ядро приложения
  - `/redis_manager` - управление Redis для кеширования
  - `/wb_api` - взаимодействие с API Wildberries
  - `/telegram` - общие компоненты для работы с Telegram
  - `/data_manager` - управление данными
  - `/access_manager` - управление доступом пользователей

- `/app/modules` - основные модули приложения
  - `/wb_adv_updater` - обновление рекламных кампаний на WB
  - `/shops_data_updater` - обновление данных магазинов
  - `/payment_compensation` - модуль компенсаций и платежей
  - `/bidder_auto_mode` - автоматическая система управления ставками
  - `/wb_keywords_parser` - парсинг и анализ ключевых слов
  - `/user_message_sender` - отправка сообщений пользователям
  - `/shop_runner` - управление магазинами
  - `/predict_ctr_exponent_settings` - настройки прогнозирования CTR
  - `/full_stat_adv_updater` - обновление полной статистики рекламы

### `/dockers`
Содержит Dockerfile для контейнеризации различных компонентов:
- Dockerfile для bidder
- Dockerfile для client_bot
- Dockerfile для updater
- Другие Dockerfile

### `/tests`
Тесты проекта:
- Юнит-тесты
- Интеграционные тесты
- Тестовые данные и моки

### `/migrations`
Миграции баз данных (SQLAlchemy/Alembic)

### `/alembic`
Конфигурация Alembic для управления миграциями базы данных

### `/python_modules`
Общие Python-модули, используемые в различных частях приложения

## Важные файлы

### `/app/__init__.py`
Инициализирует приложение и определяет точки входа для различных компонентов

### `/updater.py`
Сервис обновления данных и автоматической корректировки ставок:
- Запускает различные корутины в отдельных процессах
- Обновляет данные о CTR по схожим ключевым словам
- Обновляет ключевые слова на Wildberries

### `/app/client_bot/client_bot.py`
Основной файл клиентского бота:
- Настраивает обработчики команд
- Инициализирует middleware
- Запускает бота

### `/run_compensations.py`
Скрипт для запуска системы компенсаций

### `/docker-compose.yml`
Определяет контейнеры и их взаимодействие:
- bidder - сервис управления ставками
- bot - телеграм-бот для пользователей
- updater - сервис обновления данных
- celery - воркер для фоновых задач
- model_updater - обновление ML-моделей

## База данных и хранилища

Проект использует несколько хранилищ данных:
- PostgreSQL - для основных данных
- Redis - для кеширования и очередей
- ClickHouse - для аналитических данных (логи, статистика)
- Neo4j - для хранения графовых данных (связи между ключевыми словами)

## Воркеры и фоновые процессы

- Celery - для выполнения фоновых задач
- Multiprocessing - для параллельного выполнения обновлений
- Системные сервисы через systemd (для продакшн-среды)
