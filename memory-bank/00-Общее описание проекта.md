# Общее описание проекта Adv Bot

## Назначение проекта

Adv Bot - это автоматизированная система управления рекламными кампаниями на маркетплейсе Wildberries. Проект представляет собой многокомпонентное приложение с телеграм-ботом для взаимодействия с пользователями, аналитическим модулем и автоматизированным управлением рекламными ставками.

## Основные компоненты

### 1. Клиентский Telegram-бот
Предоставляет интерфейс для взаимодействия пользователей с системой. Позволяет:
- Управлять рекламными кампаниями
- Получать аналитику
- Настраивать автоматические стратегии
- Пополнять баланс и оплачивать услуги

### 2. Модуль работы с API Wildberries
Отвечает за взаимодействие с API Wildberries для:
- Получения данных о товарах и рекламных кампаниях
- Обновления ставок в рекламных кампаниях
- Получения статистики

### 3. Bidder (Система управления ставками)
Автоматически управляет ставками на основе настроенных стратегий:
- Анализирует эффективность ключевых слов
- Оптимизирует ставки для достижения целевых показателей
- Поддерживает автоматический режим работы

### 4. Аналитический модуль
Обрабатывает данные для предоставления пользователям аналитики:
- Анализирует эффективность рекламных кампаний
- Прогнозирует CTR (Click-Through Rate)
- Помогает оптимизировать рекламные бюджеты

### 5. Система компенсаций и платежей
Управляет финансовыми операциями:
- Работает с платежными шлюзами
- Производит компенсации при необходимости
- Ведет учет транзакций

## Технический стек

### Языки и фреймворки
- Python 3.x
- Aiogram (для Telegram-бота)
- Celery (для фоновых задач)

### Базы данных и хранилища
- PostgreSQL
- Redis (для кеширования и очередей)
- ClickHouse (для аналитики)
- Neo4j (для графовых данных)

### Инфраструктура
- Docker и Docker Compose для контейнеризации
- Kubernetes для оркестрации (опционально)
- Systemd для управления сервисами

### Библиотеки ML/AI
- TensorFlow
- Scikit-learn
- XGBoost
- Word2Vec (для обработки ключевых слов)

## Архитектура проекта

Проект разделен на микросервисы:
- `client_bot` - сервис телеграм-бота для пользователей
- `bidder` - сервис автоматического управления ставками
- `updater` - сервис обновления данных с Wildberries
- `celery` - worker для обработки фоновых задач
- `model_updater` - сервис обновления ML-моделей

## Ключевые модули

- `wb_adv_updater` - обновляет данные рекламных кампаний
- `shops_data_updater` - обновляет данные о магазинах продавцов
- `payment_compensation` - управляет платежами и компенсациями
- `bidder_auto_mode` - реализует автоматическое управление ставками
- `wb_keywords_parser` - парсит данные по ключевым словам
- `predict_ctr` - прогнозирует CTR на основе истории

## Рабочий процесс

1. Пользователь взаимодействует с ботом через Telegram
2. Бот обрабатывает запросы и передает их соответствующим модулям
3. Модуль bidder автоматически корректирует ставки согласно настроенным стратегиям
4. Система регулярно обновляет данные с Wildberries для актуальной информации
5. Аналитический модуль предоставляет отчеты и рекомендации

## Развертывание и запуск

Проект развертывается преимущественно с использованием Docker Compose:
```
docker-compose up -d
```

Также поддерживается запуск отдельных компонентов:
- `python client_bot_run.py` - запуск клиентского бота
- `python updater.py` - запуск системы обновления данных
- `celery -A celery_app worker` - запуск Celery воркера
