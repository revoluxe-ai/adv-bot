# Алгоритм работы Bidder

Bidder - это ключевой компонент системы, отвечающий за автоматическое управление ставками в рекламных кампаниях на Wildberries. Его основная задача - оптимизировать рекламные расходы и повышать эффективность рекламных кампаний.

## Принцип работы

Bidder работает по следующему алгоритму:

1. **Сбор данных**:
   - Получение текущих ставок с рекламной платформы Wildberries
   - Получение статистики показов, кликов и CTR по каждому ключевому слову
   - Получение данных о позициях товаров в поисковой выдаче
   - Анализ бюджетов и расходов

2. **Анализ данных**:
   - Расчет эффективности каждого ключевого слова (CTR, конверсия, стоимость клика)
   - Определение приоритетных ключевых слов на основе метрик эффективности
   - Группировка схожих ключевых слов на основе векторных представлений (Word2Vec)

3. **Принятие решений**:
   - Определение оптимальной ставки для каждого ключевого слова
   - Балансировка бюджета между различными ключевыми словами
   - Учет пользовательских настроек (максимальная ставка, целевая позиция)

4. **Исполнение решений**:
   - Установка новых ставок через API Wildberries
   - Мониторинг результатов изменений
   - Адаптация стратегии на основе обратной связи

## Режимы работы

### 1. Автоматический режим (Auto Mode)

В этом режиме система автоматически:
- Управляет ставками для достижения целевой позиции
- Оптимизирует расход рекламного бюджета
- Отключает неэффективные ключевые слова
- Регулирует интенсивность рекламы в течение дня на основе исторической эффективности

### 2. Режим бюджетного контроля (Budget Control Mode)

В этом режиме:
- Устанавливается дневной или недельный бюджет
- Система распределяет бюджет на ключевые слова с наилучшими показателями
- Автоматически снижает ставки при приближении к лимиту бюджета

### 3. Режим позиционирования (Position Mode)

В этом режиме:
- Для каждого ключевого слова устанавливается целевая позиция
- Система автоматически корректирует ставки для удержания указанной позиции
- Анализируется конкуренция и подбирается оптимальная ставка

## Ключевые параметры и настройки

### Настройки на уровне аккаунта
- Максимальный дневной бюджет
- Допустимое отклонение от целевых показателей
- Стратегия распределения бюджета (равномерно, приоритетно)

### Настройки на уровне рекламной кампании
- Время работы рекламы (24/7 или по расписанию)
- Приоритеты категорий ключевых слов
- Агрессивность стратегии (консервативная, умеренная, агрессивная)

### Настройки на уровне ключевого слова
- Целевая позиция
- Минимальная и максимальная ставка
- Индивидуальный бюджет (при необходимости)

## Интеграция с ML-моделями

Bidder интегрирован с несколькими ML-моделями:
1. **Модель прогнозирования CTR** - предсказывает вероятность клика на основе исторических данных
2. **Модель кластеризации ключевых слов** - группирует схожие ключевые слова для совместной оптимизации
3. **Модель прогнозирования позиции** - предсказывает позицию товара при изменении ставки

## Механизм обновления

Обновление ставок происходит по следующему графику:
- Для высокочастотных ключевых слов - каждые 15-30 минут
- Для среднечастотных ключевых слов - каждые 1-2 часа
- Для низкочастотных ключевых слов - 2-3 раза в день

## Алгоритм расчета ставки

Упрощенная формула расчета ставки:

```
новая_ставка = базовая_ставка * (1 + коэффициент_коррекции)
```

где:
- `базовая_ставка` - текущая ставка или минимальная ставка для достижения целевой позиции
- `коэффициент_коррекции` - рассчитывается на основе таких факторов как:
  - Разница между текущей и целевой позицией
  - Исторический CTR ключевого слова
  - Бюджетные ограничения
  - Конкуренция за ключевое слово
  - Время суток и день недели

## Обработка ошибок и отказоустойчивость

Система включает механизмы:
- Отслеживания ошибок API Wildberries
- Автоматического восстановления после сбоев
- Логирования всех изменений ставок
- Уведомления администраторов о критических проблемах
