# 📚 Руководство по документации бота WB Ads Manager

Полная документация разделена на 3 основных файла для удобства навигации.

---

## 📋 Структура документации

### 1. **BUTTONS_GUIDE.md** - Справочник кнопок
**Назначение:** Быстрый справочник всех кнопок в боте  
**Для кого:** Все пользователи  
**Что содержит:**
- Полный список всех кнопок, сгруппированных по экранам
- Таблицы с названиями кнопок
- Когда каждая кнопка видна пользователю
- Назначение каждой кнопки в одно предложение

**Как использовать:**
- Ищите нужный экран (например, "Меню настроек кампании")
- Находите нужную кнопку в таблице
- Читаете краткое описание назначения

**Пример:**
```
| № | Название кнопки | Назначение | Условие |
|---|---|---|---|
| 1 | Контроль ключевых слов | Управление ключевыми словами | Всегда видна |
```

---

### 2. **BUTTONS_FUNCTIONALITY.md** - Подробное описание функциональности
**Назначение:** Детальное объяснение работы каждой кнопки  
**Для кого:** Активные пользователи, которые хотят разобраться глубже  
**Что содержит:**
- Для каждой кнопки:
  - Тип кнопки (callback данные)
  - Когда видна
  - Что делает
  - Как работает (пошаговый процесс)
  - Результат нажатия
- Примеры работы процессов
- Объяснение алгоритмов

**Как использовать:**
- Когда вам нужно понять, как конкретная функция работает
- Когда хотите разобраться в деталях процесса
- Для обучения новых пользователей

**Пример:**
```
#### 1. **Контроль ключевых слов по кампании** 🔑
- **Тип:** `callbacks.SettingKeywords(...)`
- **Видна:** Всегда
- **Что делает:** 
  - Открывает список всех ключевых слов текущей кампании
  - Дает доступ к управлению каждым словом отдельно
- **Как работает:**
  1. Загружаются все `KeywordSetting` для текущей кампании
  2. Рассчитываются статусы ключевых слов (CTR, позиции, и т.д.)
  3. Отображается список с пагинацией (по 5 слов на странице)
  4. Каждое слово показывает текущий статус, позицию, CTR, просмотры, клики
```

---

### 3. **BOT_USER_INTERFACE_GUIDE.md** - Руководство для конечного пользователя
**Назначение:** Пошаговое руководство по использованию бота без технических деталей  
**Для кого:** Новые пользователи, маркетологи, менеджеры  
**Что содержит:**
- Как начать работу с ботом
- Пошаговые инструкции по всем операциям
- Объяснение терминов на простом языке
- Советы и рекомендации
- Частые вопросы и ответы
- Быстрый старт за 5 минут
- Глоссарий терминов

**Как использовать:**
- Первое знакомство с ботом
- Пошаговые инструкции для конкретной задачи
- Поиск решения для проблемы
- Обучение других пользователей

**Пример:**
```
#### 🤖 Включить/Выключить автоматическое управление (Основной переключатель)
- **Для чего**: Включить или выключить бота для этой кампании
- **Когда нужно**: Включайте, когда хотите, чтобы бот управлял ставками автоматически
- **Важно**: При включении проверяется наличие баланса
- **Если баланса нет**: Вы получите ошибку с предложением пополнить баланс
```

## 🎯 Когда использовать какой документ

### Сценарий 1: Новый пользователь хочет начать работать с ботом

1. **Начните здесь:** BOT_USER_INTERFACE_GUIDE.md
   - Прочитайте "Быстрый старт" (5 минут)
   - Следуйте пошаговым инструкциям

2. **Если нужна уточненияка:** BUTTONS_GUIDE.md
   - Найдите нужный экран
   - Посмотрите названия кнопок

3. **Если нужны подробности:** BUTTONS_FUNCTIONALITY.md
   - Найдите нужную кнопку
   - Прочитайте, как она работает

### Сценарий 2: Пользователь хочет найти нужную функцию

1. **Что вы ищете**: Функцию на конкретном экране
   - **Действие**: Откройте BUTTONS_GUIDE.md
   - **Найдите**: Нужный экран в оглавлении
   - **Результат**: Увидите все кнопки на этом экране

2. **Что вы ищете**: Функцию по названию
   - **Действие**: Откройте BOT_USER_INTERFACE_GUIDE.md
   - **Используйте**: Ctrl+F для поиска по названию
   - **Результат**: Пошаговая инструкция

3. **Что вы ищете**: Как работает функция
   - **Действие**: Откройте BUTTONS_FUNCTIONALITY.md
   - **Найдите**: Название функции
   - **Результат**: Подробное объяснение с примерами

### Сценарий 3: Возникла проблема

1. **Нужна помощь**: BOT_USER_INTERFACE_GUIDE.md
   - Откройте раздел "Частые вопросы и ответы"
   - Найдите вашу проблему
   - Следуйте предложенному решению

2. **Нужно понять процесс**: BUTTONS_FUNCTIONALITY.md
   - Найдите нужную функцию
   - Прочитайте "Как работает"
   - Разберитесь, где может быть проблема

### Сценарий 4: Обучение новых пользователей

1. **Для группы**: BOT_USER_INTERFACE_GUIDE.md
   - Раздел "Быстрый старт"
   - Раздел "Советы и рекомендации"

2. **Для индивидуального обучения**: BOT_USER_INTERFACE_GUIDE.md
   - Переходите от раздела к разделу
   - Давайте практические задания
   - Ссылайтесь на документ в случае вопросов

## 💡 Советы по использованию документации

## 📞 Обновление и поддержка документации

**Документы обновляются:**
