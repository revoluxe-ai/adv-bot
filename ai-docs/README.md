# AI Assistant Documentation

Эта директория содержит документацию, связанную с работой AI-ассистента в проекте. Здесь собраны уроки, извлеченные из ошибок, и рекомендации по работе с ассистентом.

## Содержание

- `ai_assistant_lessons.md` - Анализ ошибок и уроки, извлеченные из работы над функционалом автоматического биддера
- (будущие документы будут добавляться здесь)

## Назначение

Документация в этой директории помогает:
1. Отслеживать типичные ошибки AI-ассистента
2. Улучшать качество взаимодействия с ассистентом
3. Оптимизировать процесс разработки
4. Сохранять знания о специфике проекта

## Как использовать

При работе с AI-ассистентом рекомендуется:
1. Изучить существующие уроки перед началом новой задачи
2. Добавлять новые уроки при обнаружении ошибок
3. Обновлять документацию при изменении архитектуры проекта
