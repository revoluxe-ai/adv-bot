# Детальное описание функциональности кнопок в боте WB Ads Manager

Документ содержит подробное описание того, что делает каждая кнопка, как она работает и какие процессы инициирует.

---

## 📍 Главное меню (Start Menu)

### Меню выбора магазина

#### 1. **Панель администратора** 👤
- **Тип:** `AdminBonus(action="menu")`
- **Видна:** Только для администраторов (пользователи в списке `ADMINS`)
- **Что делает:** 
  - Переводит администратора в меню управления кабинетом и бонусами
  - Дает доступ к административным функциям
- **Как работает:**
  - При нажатии на кнопку срабатывает callback `AdminBonus(action="menu")`
  - Открывается меню администратора с опциями управления

#### 2. **Добавить магазин** ➕
- **Тип:** `callbacks.ShopNew()`
- **Видна:** Всегда
- **Что делает:** 
  - Инициирует процесс добавления нового магазина (кабинета Wildberries)
  - Начинает диалог регистрации нового кабинета
- **Как работает:**
  1. Пользователю предлагается ввести **название магазина** (кабинета)
  2. Затем просит **API токен** от Wildberries
  3. Бот проверяет валидность токена через API WB
  4. Если токен верный:
     - Создается новый `WBCabinet` в БД (если его еще нет)
     - Создается запись `WBUserCabinet` для привязки кабинета к пользователю
     - Бот запускает `ShopDataUpdater` для загрузки всех кампаний с WB
     - Пользователь видит обновленный список магазинов
  5. Если токен невалиден - пользователю показывается ошибка

#### 3. **[Название магазина]** 🏪
- **Тип:** `callbacks.Shop(action="select", wb_user_cabinet_original_id=...)`
- **Видна:** Динамически для каждого добавленного магазина
- **Что делает:** 
  - Переводит пользователя в меню выбранного магазина
  - Загружает список всех кампаний этого магазина
- **Как работает:**
  1. При нажатии сохраняется ID выбранного магазина (`wb_user_cabinet_original_id`)
  2. Из БД загружаются все `AdvSetting` (кампании), связанные с этим магазином
  3. Отображается меню магазина со списком кампаний и дополнительными опциями

## 🏪 Меню магазина (Shop Menu)

### Основное меню магазина

#### 1. **Автоматические рекламные кампании** 📊
- **Тип:** `callbacks.ChoiceAdvPaginator(wb_user_cabinet_original_id=..., page=1)`
- **Видна:** Если:
  - Есть активные кампании ИЛИ
  - Баланс кабинета > 0 ИЛИ
  - Срок действия подписки еще не истек
- **Что делает:** 
  - Переводит пользователя в список всех кампаний магазина
  - Отображает кампании с пагинацией
- **Как работает:**
  1. Загружаются все кампании `AdvSetting`
  2. Кампании сортируются: сначала активные, потом неактивные
  3. Отображаются по 5 кампаний на странице (по умолчанию)
  4. Каждая кампания показывает:
     - Текущую целевую позицию (если есть)
     - Статус проверки (✅ или ❓)
     - Название кампании и ID
     - Включен ли бот для этой кампании
     - Статус активности кампании на WB

#### 2. **Пополнить баланс** 💰
- **Тип:** `callbacks.AddBalance(wb_cabinet_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Инициирует процесс пополнения баланса кабинета
  - Переводит в меню выбора способа пополнения
- **Как работает:**
  1. Пользователю показываются доступные способы пополнения
  2. При выборе суммы создается запись `WBBalancePayment`
  3. После подтверждения платежа (`ConfirmAddBalance`):
     - Баланс кабинета увеличивается на указанную сумму
     - В БД сохраняется запись о платеже с временем транзакции
  4. Пользователю показывается подтверждение успешного пополнения

#### 3. **Отключить все кампании** ⏹️
- **Тип:** `callbacks.TurnBot(action="off_all", wb_user_cabinet_original_id=...)`
- **Видна:** Только если есть активные (включенные) кампании
- **Что делает:** 
  - Выключает автоматический бот для всех кампаний магазина одновременно
  - Прекращает автоматическое управление всеми кампаниями
- **Как работает:**
  1. Находятся все `AdvSetting` для этого магазина
  2. У каждой кампании устанавливается `bot_active = False`
  3. Изменения сохраняются в БД
  4. Пользователь возвращается в меню магазина

#### 4. **Вернуться к списку магазинов** ⬅️
- **Тип:** `callbacks.Start()`
- **Видна:** Всегда
- **Что делает:** 
  - Возвращает пользователя в главное меню выбора магазинов
- **Как работает:**
  - Клиринг текущего состояния
  - Загрузка списка всех магазинов пользователя
  - Отображение главного меню

## 📊 Кампании (Campaigns)

### Список кампаний с пагинацией

#### 1. **[Название кампании]** (кликабельное название)
- **Тип:** `callbacks.Adv(action="select", adv_original_id=..., wb_user_cabinet_original_id=...)`
- **Видна:** Динамически для каждой кампании
- **Что делает:** 
  - Открывает меню настроек выбранной кампании
  - Загружает все параметры и состояние кампании
- **Как работает:**
  1. Загружается объект `AdvSetting` с ID выбранной кампании
  2. Если это релевантная кампания поиска, загружается связанная кампания аукциона
  3. Загружаются все ключевые слова для кампании
  4. Загружается фото товара (NMID)
  5. Отображается полное меню настроек кампании со всеми доступными действиями

#### 2. **⬅️ (Предыдущая страница)**
- **Тип:** `callbacks.ChoiceAdvPaginator(wb_user_cabinet_original_id=..., page=page-1)`
- **Видна:** Если текущая страница > 1
- **Что делает:** 
  - Переходит на предыдущую страницу списка кампаний
- **Как работает:**
  - Уменьшается номер страницы на 1
  - Пересчитывается `start_index` и `end_index` для отображения кампаний
  - Отображаются кампании со страницы `page-1`

#### 3. **➡️ (Следующая страница)**
- **Тип:** `callbacks.ChoiceAdvPaginator(wb_user_cabinet_original_id=..., page=page+1)`
- **Видна:** Если есть еще кампании на следующей странице
- **Что делает:** 
  - Переходит на следующую страницу списка кампаний
- **Как работает:**
  - Увеличивается номер страницы на 1
  - Проверяется, что `(page-1)*on_page + len(advs_on_page) < total_advs`
  - Отображаются новые кампании со страницы `page+1`

#### 4. **Сбросить фильтр** 🔄
- **Тип:** `callbacks.ChoiceAdvPaginator(wb_user_cabinet_original_id=..., page=..., reset_filter=True)`
- **Видна:** Только если активен какой-либо фильтр
- **Что делает:** 
  - Очищает примененный фильтр по кампаниям
  - Возвращает полный список кампаний
- **Как работает:**
  1. Устанавливается `reset_filter=True` в callback
  2. В обработчике: `await state.update_data(filter_advs=None)`
  3. Пересчитывается список кампаний без фильтра
  4. Отображается полный список кампаний

#### 5. **Вернуться к меню магазина** ⬅️
- **Тип:** `callbacks.Shop(action="select", wb_user_cabinet_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Возвращает пользователя в меню магазина
- **Как работает:**
  - Загружаются настройки магазина
  - Отображается меню магазина

#### 6. **Полностью обновить мета-данные от WB** 🔄
- **Тип:** `callbacks.UpdateCompanyFromWB(wb_user_cabinet_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Загружает свежие данные о всех кампаниях и товарах с сервера WB
  - Обновляет кэш и синхронизирует состояние с WB
- **Как работает:**
  1. Создается экземпляр `WBApi` с токеном магазина
  2. Запускается `ShopDataUpdater.update_advs_data()`:
     - Загружаются все кампании (поиск + аукцион)
     - Загружаются все товары для каждой кампании
     - Загружаются ключевые слова для каждого товара
     - Вся информация сохраняется/обновляется в БД
  3. Пользователю показывается сообщение об успешном обновлении
  4. Отображается обновленный список кампаний

## ⚙️ Настройки кампании (Campaign Settings)

### Основное меню настроек АРК

#### 1. **Контроль ключевых слов по кампании** 🔑
- **Тип:** `callbacks.SettingKeywords(adv_original_id=..., type="by_adv", page=1)`
- **Видна:** Всегда
- **Что делает:** 
  - Открывает список всех ключевых слов текущей кампании
  - Дает доступ к управлению каждым словом отдельно
- **Как работает:**
  1. Загружаются все `KeywordSetting` для текущей кампании
  2. Рассчитываются статусы ключевых слов (CTR, позиции, и т.д.)
  3. Отображается список с пагинацией (по 5 слов на странице)
  4. Каждое слово показывает текущий статус, позицию, CTR, просмотры, клики

#### 2. **Включить/Выключить автообновление белого списка** (WL Auto-Update)
- **Тип:** `callbacks.TurnParsing(action="on"/"off", adv_original_id=..., wb_user_cabinet_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Включает/выключает автоматическое обновление белого списка ключевых слов
  - При включении: бот автоматически добавляет новые релевантные слова в БС
- **Как работает:**
  1. При нажатии проверяется текущее состояние режима парсинга
  2. Переключается значение в `AdvSetting.parsing_mode`
  3. Если включен (`action="on"`):
     - Активируется фоновый процесс парсинга
     - Бот периодически проверяет новые ключевые слова по товару
  4. Если выключен (`action="off"`):
     - Прекращается автоматическое добавление слов
     - Только пользователь может добавлять слова вручную
  5. Пользователю показывается новый статус режима

#### 3. **Включить/Выключить автоуправление целевой позицией** (Target Position Auto-Manage)
- **Тип:** Нужно найти в коде
- **Видна:** Всегда
- **Что делает:** 
  - Включает/выключает автоматическое управление целевой позицией ключевых слов
  - При включении: бот автоматически подбирает ставки для достижения целевой позиции
- **Как работает:**
  1. Проверяется текущее состояние режима управления позицией
  2. Переключается значение в `AdvSetting.auto_position_mode`
  3. При включении:
     - Сохраняется текущая целевая позиция (если установлена)
     - Бот начинает автоматически рассчитывать ставки
  4. При выключении:
     - Целевая позиция сохраняется, но не используется для расчетов
  5. Отображается новый статус

#### 4. **Переключить на общую статистику заказов / на заказы только из рекламы** (Orders Source)
- **Тип:** `OrdersSourceToggle(...)`
- **Видна:** Всегда
- **Что делает:** 
  - Переключает источник данных для расчета статистики
  - **Режим 1:** Используются только заказы из рекламы (точнее)
  - **Режим 2:** Используются все заказы товара включая органические (менее точно)
- **Как работает:**
  1. Проверяется текущий режим источника заказов
  2. При переключении обновляется `AdvSetting.use_all_orders` (True/False)
  3. Все последующие расчеты CTR, ROI, CPA используют выбранный источник
  4. Пользователю показывается новый режим

#### 5. **Переключить на режим прогноза CTR v1 / v2** (CTR Prediction Mode)
- **Тип:** `PredictCTRModeToggle(...)`
- **Видна:** Всегда
- **Что делает:** 
  - Переключает версию алгоритма прогнозирования CTR
  - **v1:** Старый алгоритм, быстрее
  - **v2:** Новый алгоритм, точнее
- **Как работает:**
  1. Проверяется текущая версия алгоритма
  2. При переключении обновляется `AdvSetting.predict_ctr_version`
  3. Для всех ключевых слов пересчитываются прогнозы CTR
  4. Пользователю показывается новая версия

#### 6. **План продаж** 📈
- **Тип:** `SalesPlanSettings(...)`
- **Видна:** Всегда
- **Что делает:** 
  - Открывает меню настройки плана продаж
  - Позволяет установить целевые показатели дневных продаж
- **Как работает:**
  1. Открывается форма с тремя полями:
     - Количество продаж в день (план)
     - Целевая себестоимость заказа
     - Максимальная себестоимость заказа
  2. Пользователь может изменить любое значение
  3. Новые значения сохраняются в БД
  4. Бот использует эти значения для расчета оптимальных ставок

#### 7. **Включить/Выключить автоматическое управление** (Bot On/Off)
- **Тип:** `callbacks.TurnBot(action="on"/"off", adv_original_id=..., wb_user_cabinet_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Основной переключатель включения/выключения бота для кампании
  - При включении: бот начинает управлять ставками, позициями и бюджетом
  - При выключении: все автоматизация прекращается
- **Как работает:**
  1. **На включение (`action="on"`)**:
     - Проверяется наличие достаточного баланса для кампании
     - Если баланса недостаточно - показывается ошибка и предложение пополнить
     - Если баланс достаточный:
       - Устанавливается `adv.bot_active = True`
       - Запускаются все фоновые процессы управления
       - Пользователю показывается "Включаю бота"
  2. **На выключение (`action="off"`)**:
     - Устанавливается `adv.bot_active = False`
     - Прекращаются все фоновые процессы
     - Ставки и позиции замораживаются в текущем состоянии

#### 8. **Управление ставкой (CPM)** 💵
- **Тип:** `callbacks.CPMSettingMenu(action="...", adv_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Открывает меню управления ставками (CPM) для кампании
  - Позволяет установить различные стратегии ставок
- **Как работает:**
  1. Открывается меню с опциями:
     - Изменить фиксированную ставку
     - Включить режим автоставок
     - Установить минимальную ставку
     - И т.д.
  2. При выборе ставка сохраняется в `AdvSetting.cpm`
  3. Все последующие аукционы используют новую ставку

#### 9. **Шаблоны не релевантных фраз** (Black List Templates)
- **Тип:** `callbacks.AddBlackPhrasesTemplates(adv_setting_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Открывает меню управления шаблонами/паттернами минус-слов
  - Позволяет создавать правила для автоматического исключения нерелевантных фраз
- **Как работает:**
  1. Пользователю показываются существующие шаблоны
  2. Можно добавить новый шаблон:
     - Ввести паттерн (например, "не работает" или "дешево")
     - Шаблон сохраняется в `AdvSetting.black_phrases`
  3. При включении автопарсинга: система автоматически добавляет минус-слова по этим шаблонам

#### 10. **Добавить фразы в продвижение (Белый список)** ✅
- **Тип:** `callbacks.AddWhitePhrases(adv_setting_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Позволяет пользователю вручную добавить ключевые слова в белый список (БС)
- **Как работает:**
  1. Бот запрашивает фразы у пользователя: "Введите фразы для добавления"
  2. Пользователь вводит фразы (можно через запятую или каждую на новой строке)
  3. Для каждой фразы создается запись `KeywordSetting`:
     - `hard_status = WHITE_LIST` (статус: в белом списке)
     - `adv_original_id = current_adv_id`
  4. Все фразы загружаются на WB в кампанию поиска
  5. Пользователю показывается "Фразы успешно добавлены"

#### 11. **Добавить РЕЛЕВАНТНЫЕ фразы** (Relevant Phrases)
- **Тип:** `callbacks.AddRelevantPhrases(adv_setting_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Позволяет пользователю добавить фразы в "релевантные" (automatic mode)
  - Эти фразы будут управляться ботом автоматически (не фиксированы в БС)
- **Как работает:**
  1. Бот запрашивает фразы: "Введите релевантные фразы"
  2. Пользователь вводит фразы
  3. Для каждой фразы создается запись `KeywordSetting`:
     - `hard_status = AUTO_MODE` (статус: авто)
     - `relevant = True` (отмечена как релевантная)
  4. Фразы добавляются в список кандидатов для автоуправления
  5. Пользователю показывается "Фразы успешно добавлены в авто список"

#### 12. **Выгрузить ключи в csv-файл** 📥
- **Тип:** `callbacks.DownloadCSV(adv_setting_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Экспортирует все ключевые слова кампании в CSV файл
- **Как работает:**
  1. Загружаются все ключевые слова кампании
  2. Формируется CSV файл с колонками:
     - Слово
     - Позиция
     - CTR
     - Статус (авто/БС/черный список)
     - Просмотры, клики, конверсии, и т.д.
  3. Файл отправляется пользователю через бот

#### 13. **Включить все фразы в аукционе / Включить фикс. в аукционе** (Auction Mode)
- **Тип:** Зависит от режима
- **Видна:** Всегда
- **Что делает:** 
  - Переключает режим участия в аукционе
  - **Режим 1:** Все фразы участвуют в аукционе (динамические ставки)
  - **Режим 2:** Фиксированная ставка для всех фраз
- **Как работает:**
  1. При нажатии проверяется текущий режим
  2. Переключается `AdvSetting.auction_mode`
  3. При перключении все ставки пересчитываются согласно новому режиму

#### 14. **История позиций ключевых слов** 📊
- **Тип:** `callbacks.KeywordPositionHistory(adv_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Показывает историю изменения позиций ключевых слов за последний период
- **Как работает:**
  1. Загружаются исторические данные позиций из БД (обычно за последние 30 дней)
  2. Для каждого ключевого слова строится график:
     - Ось X: дата/время
     - Ось Y: позиция (1, 2, 3, и т.д.)
  3. Показывается таблица с минимальной, максимальной и текущей позицией
  4. Это помогает отследить эффективность управления позициями

     - Кнопка "Изменить"

     - Пользователь вводит новое значение (например, "0.5%")
     - Значение сохраняется в `AdvSetting.min_ctr`
  3. Система автоматически отключает слова с CTR ниже этого порога

  3. При включении:
     - Бот может снизить ставку, чтобы вернуть позицию к началу (для переинициализации)
  4. При выключении:
     - Сброс позиций запрещен, ставка только повышается/понижается плавно

## 🔑 Ключевые слова (Keywords)

### Список ключевых слов с пагинацией

#### 1. **[Ключевое слово с информацией]** (Название слова с данными)
- **Тип:** `callbacks.SettingKeyword(keyword_setting_original_id=...)`
- **Видна:** Динамически для каждого ключевого слова
- **Что делает:** 
  - Открывает меню управления конкретным ключевым словом

  1. Загружается `KeywordSetting` с информацией о слове

     - Прогнозируемый CTR (AI)
     - Просмотры, клики, конверсии
  3. Отображается меню управления этим словом

#### 2. **⬅️ (Предыдущая страница)**
- **Тип:** `callbacks.SettingKeywords(adv_original_id=..., page=page-1)`

- **Что делает:**

- **Как работает:**
  - Уменьшается номер страницы
  - Отображаются ключевые слова со страницы page-1

#### 3. **➡️ (Следующая страница)**
- **Тип:** `callbacks.SettingKeywords(adv_original_id=..., page=page+1)`
- **Видна:** Если есть еще слова на следующей странице
- **Что делает:** 
  - Переходит на следующую страницу списка ключевых слов
- **Как работает:**
  - Увеличивается номер страницы
  - Отображаются ключевые слова со страницы page+1

  - Возвращает полный список слов
- **Как работает:**
  - Устанавливается `reset_filter=True`
  - В обработчике очищается `filter_advs` в состоянии
  - Отображается полный список ключевых слов

  4. На кнопке появляется индикатор активного фильтра

### Меню отдельного ключевого слова

#### 1. **Тестировать дальше** (Test Further)
- **Тип:** `callbacks.ChangeKeywordHardStatus(new_hard_status=-1, keyword_setting_original_id=...)`
- **Видна:** Если:
  - Статус слова = BAD (плохой)
  - Позиция != max_position (не максимальная позиция)
- **Что делает:** 
  - Переводит слово в режим "продолжить тестирование"
  - Бот повышает ставку, чтобы поднять позицию и повторно оценить CTR
- **Как работает:**
  1. Устанавливается `hard_status = -1` (состояние тестирования)
  2. Ставка повышается на заранее определенный процент
  3. Слово остается активным в кампании
  4. Бот продолжает мониторить его статистику
  5. После улучшения позиции пересчитывается CTR и принимается новое решение

#### 2. **В авто** (To Auto Mode)
- **Тип:** `callbacks.ChangeKeywordHardStatus(new_hard_status=0, keyword_setting_original_id=...)`
- **Видна:** Если слово находится в:
  - Черном списке (BLACK_LIST)
  - Выключено (TURN_OFF)
  - Белом списке (WHITE_LIST)
- **Что делает:** 
  - Переводит слово в режим автоматического управления (АВТО)
  - Бот сам решает, включить ли слово в БС на основе CTR
- **Как работает:**
  1. Устанавливается `hard_status = AUTO_MODE (0)`
  2. Слово переводится в актив кампании, если оно было выключено
  3. На WB отправляется команда активировать слово
  4. Бот начинает мониторить его эффективность
  5. Если CTR хороший - может автоматически добавить в БС
  6. Если CTR плохой - может выключить

#### 3. **В белый список** (To White List)
- **Тип:** `callbacks.ChangeKeywordHardStatus(new_hard_status=2, keyword_setting_original_id=...)`
- **Видна:** Если слово находится в:
  - Черном списке (BLACK_LIST)
  - Выключено (TURN_OFF)
  - Авто режиме (AUTO_MODE)
- **Что делает:** 
  - Переводит слово в белый список (БС)
  - Слово фиксируется на определенной ставке и управляется как закупка с целевой позицией
- **Как работает:**
  1. Устанавливается `hard_status = WHITE_LIST (2)`
  2. На WB отправляется команда добавить слово в закупку (БС) кампании поиска
  3. Устанавливается целевая позиция для этого слова
  4. Ставка блокируется и не изменяется в авторежиме
  5. Бот только поднимает позицию, если нужно

#### 4. **Добавить в релевантные фразы / Удалить из релевантных фраз** (Toggle Relevance)
- **Тип:** `RelevantKeywordStatusSetting(new_relevant_status=True/False, keyword_setting_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Переключает отметку "релевантное" для слова
  - Релевантные слова используются алгоритмом для выбора стратегии
- **Как работает:**
  1. При нажатии переключается `keyword.relevant`
  2. Если было False -> становится True, и наоборот
  3. Информация сохраняется в БД
  4. Отображается новый статус слова

#### 5. **Отключить (релевантная фраза)** (Disable)
- **Тип:** `callbacks.ChangeKeywordHardStatus(new_hard_status=3, keyword_setting_original_id=...)`
- **Видна:** Если слово:
  - В авто режиме (AUTO_MODE)
  - В белом списке (WHITE_LIST)
  - Недостаточно просмотров для оценки
- **Что делает:** 
  - Выключает слово (TURN_OFF)
  - Слово остается в кампании, но не показывается в поиске
- **Как работает:**
  1. Устанавливается `hard_status = TURN_OFF (3)`
  2. На WB отправляется команда выключить слово
  3. Слово становится невидимым в поиске, но сохраняется в БД
  4. Пользователь может позже его снова включить

#### 6. **В список не релевантных фраз** (To Black List)
- **Тип:** `callbacks.ChangeKeywordHardStatus(new_hard_status=1, keyword_setting_original_id=...)`
- **Видна:** Если слово:
  - В авто режиме (AUTO_MODE)
  - В белом списке (WHITE_LIST)
  - Выключено (TURN_OFF)
- **Что делает:** 
  - Переводит слово в черный список (минус-слова)
  - Слово больше не будет показываться при поиске по этому слову
- **Как работает:**
  1. Устанавливается `hard_status = BLACK_LIST (1)`
  2. На WB отправляется команда добавить слово в минус-слова
  3. Слово добавляется в список `AdvSetting.minus_keywords`
  4. Система не будет больше предлагать это слово для добавления
  5. Пользователю показывается "Ключ добавлен в список не релевантных фраз"

#### 7. **Проверить позицию** (Check Position)
- **Тип:** `callbacks.CheckPosition(keyword_setting_original_id=..., adv_original_id=...)`
- **Видна:** Всегда
- **Что делает:** 
  - Запрашивает текущую позицию ключевого слова на WB
  - Обновляет информацию о позиции в режиме реального времени
- **Как работает:**
  1. Запрашивается текущая позиция слова на WB
  2. Позиция сохраняется в таблицу `KeywordPosition`
  3. Если позиция изменилась:
     - Пересчитываются рекомендуемые ставки
     - Может быть принято решение об автоматическом управлении
  4. Пользователю показывается текущая позиция
  5. Сохраняется в истории для отслеживания тренда

#### 8. **Изменить ставку** (Change CPM/Bid)
- **Тип:** `callbacks.ChangeCPM(adv_setting_original_id=...)`

     - `(позиция)` - показывается только если есть целевая позиция
     - `[Название кампании]` - название из БД
  2. При нажатии:
     - Загружаются все параметры кампании
     - Загружаются все ключевые слова
     - Загружается фото товара
     - Отображается меню настроек кампании

## ⚠️ Важные замечания о функциональности

### Синхронизация с WB API
- Большинство операций требуют синхронизации с сервером Wildberries
- Все изменения ставок, ключевых слов и статусов отправляются на WB через API

### Сохранение состояния
- Состояние пользователя сохраняется в FSMContext (конечный автомат состояний)
- История операций сохраняется в БД для отслеживания и отладки

### Проверка доступа
- Для администраторских функций проверяется принадлежность пользователя к списку `const.ADMINS`
- Для операций с кампаниями проверяется, что кампания принадлежит пользователю

### Обработка ошибок
- При недостаточном балансе пользователю показывается ошибка и предложение пополнить
- При ошибках API от WB показывается сообщение об ошибке
- Все ошибки логируются для отладки
