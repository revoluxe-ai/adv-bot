# Справочник кнопок в боте WB Ads Manager

Документ содержит все названия кнопок в Telegram боте, сгруппированные по местам расположения и функциональности.

---

## 📍 Главное меню (Main Menu)

Показывается после `/start` или нажатия «Назад» на странице «Мои магазины». Клавиатура: `get_main_menu_keyboard()` (`shop_choice_message.py`).

| № | Название кнопки | Назначение | Условие |
|---|---|---|---|
| 1 | Панель администратора | Доступ к админ-панели | Только для администраторов (ADMINS) |
| 2 | Мои магазины | Переход на страницу «Мои магазины» (список магазинов) | Всегда видна |
| 3 | Мой баланс | Меню баланса пользователя | Всегда видна |
| 4 | Показать инвайт | Показать инвайт-ссылку | Всегда видна |

---

## 📋 Страница «Мои магазины» (Shops List)

Показывается по кнопке «Мои магазины» из главного меню или по кнопкам «Вернуться к списку магазинов» / «К списку магазинов». Клавиатура: `get_shops_list_keyboard()` (`shop_choice_message.py`).

| № | Название кнопки | Назначение | Условие |
|---|---|---|---|
| 1 | ➕Добавить магазин | Добавление нового магазина | Всегда видна |
| 2 | [Название магазина ✅/❌] | Выбор магазина для работы | До 20 на странице, пагинация при большем числе |
| 3 | ⬅️ Назад / Вперёд ➡️ | Переключение страницы списка | Если страниц больше одной |
| 4 | Назад | Возврат в главное меню | Всегда видна |

## 📝 Примечания

### Динамические элементы:
- **[Название магазина]** - берется из БД, заполняется динамически
- **[Название кампании]** - берется из БД, заполняется динамически
- **[Ключевое слово с информацией]** - формируется из данных ключевого слова
- **([число])** - значение из БД, может быть изменено
- **⬅️, ➡️** - стрелки для навигации между страницами
- **✅, ❌, ➕, ➖, 🔄, 🔙, 💰** - эмодзи-индикаторы

### Условия отображения:
- **Всегда видна** - кнопка отображается при нормальных условиях
- **Динамически** - кнопка появляется в зависимости от данных
- **Зависит от состояния** - кнопка зависит от текущего статуса
- **Только для администраторов** - видна только для пользователей в списке ADMINS
- **Если есть активные кампании** - видна только при наличии АРК
